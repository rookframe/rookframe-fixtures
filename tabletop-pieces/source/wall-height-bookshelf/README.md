# Wall-height Bookshelf

Original Rookframe model authored through Blender MCP. Five shelves, 61 books,
1.5 m wide × 2.8 m tall × 0.5 m deep. Stock Godot Prop collision encloses the
closed cabinet. Content ID: `wall-height-bookshelf`.

Runtime model: 3,620 triangles, one mesh, one PBR material, three 2048px maps.
The editable Blend retains the detailed source, low-poly mesh, and packed
textures. The runtime GLB includes only the optimized bookshelf.

Weathered oak uses the existing Builder Reference Finishes CC0 timber maps.
The leather textures, book design, hardware, and geometry are original.
The application catalogue preview is rendered from the exported low-poly GLB.

Timber source: [ambientCG Wood 076](https://ambientcg.com/a/Wood076), CC0; used by the published Builder Reference Finishes wall.
